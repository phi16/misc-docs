# 「3」は何型か——リテラル解決の比較

数値リテラルの型をどう決めるかは、地味に見えて、言語設計の態度がもっとも正直に
出る角のひとつです。どの言語もここで何かを妥協しており、妥協の仕方がその言語の
性格を語ります。

## 各言語の答え

- **C 系**：`3` は `int`。あとは暗黙の昇格・変換の規則表が引き受ける。
  「添字のつもりの int が座標の float に化ける」型の静かなバグの母。
- **Haskell**：`3` は `fromInteger 3 :: Num a => a` と多相に読む——ここまでは美しい。
  しかし曖昧さが残ったときのために **defaulting 規則**がある：モジュールごとの
  `default` 宣言、`Integer` → `Double` の既定列、GHCi では ExtendedDefaultRules。
  型クラスの整った世界の中で、ここだけ場当たり的な規則が同居している、と
  よく指摘される角です。
- **Rust**：整数リテラルは推論で決め、決まらなければ **`i32` に fallback**。
  エラーメッセージに `{integer}` という「まだ決まっていない数」が現れるのは、
  遅延解決をユーザーに見せている点で面白い部分です。ただし最後の i32 は
  純粋に恣意的な既定。
- **Swift**：`ExpressibleByIntegerLiteral` 等のプロトコル群。文脈の型がリテラルの
  解釈を選ぶ、という方向は SC0 に近い。既定は `Int`。
- **Lean 4**：`(37 : α)` は **`OfNat α 37` のインスタンス探索**になります。クラスが
  **リテラルの値そのものでインデックスされている**のが特徴で、「この型は 0 と 1 だけ
  リテラルで書ける」（`OfNat P 1` だけ定義する）のような値単位の制御ができる。
  出力方向（期待型から辞書を引く）の解決という点で、SC0 にいちばん近い先行例です。

## SC0 の答え

SC0 の立場は 3 つの決定に要約できます。

1. **変換もリテラルも `From` 一本**。`3` は「`N` のリテラルから期待型への `From`」の
   探索であり、小数は `Rational = {num, den}` を経由する。型検査器にリテラル専用の
   特殊処理を持たない（Lean の OfNat と同じ発想を、変換一般と統一した形）。
2. **既定型を持たない**。文脈から決まらなければ**曖昧エラー**。Haskell の defaulting・
   Rust の i32 fallback にあたるものが存在しない（No ad-hoc：黙って選ばない）。
   エラーは「`5 as N` / `5 as Z` / `5 as R` のように注釈して」と促す形で出ます。
3. **リテラルは「変換される」のではなく「生まれる」（born-as）**。期待型が未解決の
   メタでも即コミットせず、文脈が型を確定させた時点でその型として生まれる。
   これが数値だけでなく **Vec・レコードのリテラルにも一様に**効いて、
   `iterate 24 [0.0, 0.0] step` の `[0.0, 0.0]` が結果型から `Complex` として
   生まれる、といった注釈なしの nominal 構築を可能にしています。

ひとつだけ意図的な非対称があります：数値リテラルは無既定（曖昧＝エラー）ですが、
**brace リテラル（`[…]` / `{…}`）は最後まで未確定なら構造的な Vec / Record を既定**と
します。数値の「N か Z か R か」は意味の選択ですが、brace の構造形は
「nominal に生まれなかったときの自然な残余」だから、という区別です。

## 解決の順序という難問

リテラルの型は「左から右に読んで決まる」とは限りません。結果型から逆流したり、
隣のオペランドから決まったり、インスタンス探索の結果として決まったりする。
SC0 はこれを、リテラル・詰まった引数・インスタンス探索・born を**同じ fixpoint** で
順序非依存に解くことで扱っています（[開発ドキュメント](dev/elaboration.md)）。
Rust の `{integer}` が見せている「まだ決まっていない数」を、システム全体の
正規の状態として真面目に運用している、と言うこともできます。

現状の限界も記録しておきます：parametric instance と裸の整数リテラルの組み合わせでは
結果型の注釈がオペランドまで届かないことがあり（`([1,2] + [3,4]) as Vec 2 N`）、
リテラル解決の trial が型検査時間の主因になった実測もあります（determinate 化が
将来の整理として記録済み）。丁寧にやってもなお非自明な角である、ということ自体が
この主題の面白さです。
