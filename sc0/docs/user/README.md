# SC0 ユーザードキュメント — 概観

SC0 は依存型付き λ 計算を核とする言語で、画像・音・メッシュなどを
「数学的な関数の記述 → 型に導かれた実体化」という流れで生成します。
たとえば `R² → R³` の関数を書き、それを解像度指定でサンプリングすると画像（`Buffer`）になります。

```
rasterize {lo = [0.0, 0.0], hi = [1.0, 1.0], res = [64, 64]}
  (λp. [p.0, p.1, 0.0])
-- : Buffer 2 [64, 64] (Vec 3 R)  — 左下が黒、右上へ赤緑のグラデーション
```

## 特徴の一覧

各項目の詳細はリンク先にあります。**太字**は他の言語にあまり見られない、SC0 に固有性の高いものです。

### 言語コア

- 純粋・正格な依存型付き λ 計算。値はすべて式で、関数は第一級（[構文](user/syntax.md)）
- **関数の再帰はない**（自己再帰も相互再帰も書けない。`let f = … f …` は不可）。
  反復は有界反復 `iterate` / `for` で書く（[評価モデル](user/evaluation.md)）
- 依存型：`Vec n R` や `Buffer d shape T` のように、長さ・形状が型に現れる（[型システム](user/types.md)）
- 暗黙引数 `?x` とホール `?` / `_`。ホールを含む**未完成プログラムは正規の状態**として扱われ、
  各ホールの期待型が報告される
- レコード型（telescope：後のフィールドの型が前のフィールドに依存できる）
- payload 付き enum（`enum Maybe a { some a, none }`）と `case` 分岐
- **nominal 型**：`nominal Complex = Vec 2 R` は右辺と別物の剛体な型。
  構築はリテラルの born-as（文脈の期待型がリテラルの生まれを決める）で行う
- 命題的等価 `Id` / `_≡_` と除去子 `J`。`trustMe` で書いた**等式は評価時に実行時検査され、
  嘘の等式は honest にエラーになる**
- ユーザー定義の中置演算子（fixity 宣言つき）。**記号にデフォルトの優先順位はない**
  （`+` の fixity すら標準ライブラリが宣言している）

### オーバーロードとリテラル

- **型クラス＝ただの nominal レコード、インスタンス＝ただの値**。専用機構は探索だけ
  （[クラスとオーバーロード](user/classes.md)）
- parametric instance（関数として書くインスタンス。`AddOp a a` から `AddOp (Vec n a) (Vec n a)` を再帰導出）
- **数値・ベクトル・レコードのリテラルはすべて一本のクラスで解決**される（`From`）。
  文脈から型が決まらないリテラルは黙って既定型に落ちず**曖昧エラー**になる

### 実体化と実行

- 関数（`Vec d R -> T`）とバッファ（`Buffer d shape T`）を型で分離し、
  `render` / `rasterize` / `parallel` で実体化、`sampler` で読み戻す（[評価モデル](user/evaluation.md)）
- `parallel` は**数値カーネルにコンパイルされて一括実行される**。カーネル化できない場合は
  黙って遅い経路に落ちず**エラー**になる（明示の `*_fallback` で per-sample 実行を選べる）
- **`extern`＝外部 runtime 入力**：値をソースに書かず実行環境が供給する宣言。
  カーネルは値について symbolic にコンパイルされるので、**スライダが再コンパイルなしで
  ライブに効く**
- カーネルは WGSL に翻訳され、**Web では実 GPU（WebGPU）で実行される**（CPU 実行との差分検証つき）
- **音**：`Stream`（状態を持つ無限サンプル列）と `Trigger`（疎イベント）・ポリフォニー。
  **WebAudio を GPU と同じ透明アクセラレータとして使い**、`hold` 宣言で
  **鳴らしたままコードを編集できる**（crossfade。[音とストリーム](user/stream.md)）
- **型は実行時に消去される**（`Vec n T` と `Vec m T` は同表現。証明も消える）

### モジュールとライブラリ

- モジュールシステム：`import` / `open import` / 選択 import / `private` / 再公開
  （[モジュール](user/modules.md)）
- 標準ライブラリ：`std`（Prelude・常時取り込み）/ `base` / `prim` / `algebra` / `math` / `mesh`
  （[標準ライブラリ](user/stdlib.md)）
- **メッシュに特権的な「Mesh 型」はない**。トポロジは型インデックス `j : Topo` に載り、
  属性は `Point j -> A` のただの関数（[メッシュ](user/mesh.md)）

### 環境

- CLI（評価・PNG 書き出し）、LSP（VS Code：診断・hover・定義ジャンプ）（[動かし方](user/getting-started.md)）
- Web 環境：テキストとノードグラフの**双方向編集**（真実はプログラムひとつ）、
  `@` マーカーによるノード粒度の制御（折り畳み）、
  ノード埋め込み view（画像・曲線・3D・スライダ…）、incremental な再計算（Cook）
  （[Web 環境](user/web-ui.md)）

## このドキュメントの書き方について

- チュートリアルは [動かし方](user/getting-started.md) の冒頭に最小限だけあります。
  残りは機能の網羅的な列挙です。
- 「実装を読まないと分からない挙動」（遅延評価の単位・リテラル解決の順序・IR 化の条件など）は
  **⚙ 実装メモ** として本文中に明示します。
- 未検証・流動的な記述には（要検証）と付けています。
