# SC0 ドキュメント

SC0 は、メッシュ・画像・音・その他さまざまなものの生成や編集を行うための言語と環境です。
依存型付き λ 計算を核に、テキストとノードグラフの双方向編集、型に導かれた実体化
（関数 → バッファ）を備えます。方向性は Houdini に近く、記述は数学に近い形を目指しています。

まず全体像を掴むには **[SC0 とは — 狙いと指針](vision.md)** を読んでください
（何を狙う言語・環境か、既存のものとの違い、判断の拠り所）。

このドキュメントは 2 部構成です。

- **[ユーザードキュメント](user/)** — SC0 を「使う」人向け。言語の全機能・標準ライブラリ・
  Web 環境の操作を網羅的に列挙します。チュートリアルは最小限で、
  「どんな機能があるか（特に他の言語にあまりないもの）」と
  「実装を読まないと分からない挙動」を明示することを重視しています。
- **[開発ドキュメント](dev/)** — SC0 の実装に手を入れる人向け。
  アーキテクチャ・ビルド・テスト・各モジュールの責務。

## 閲覧方法

このドキュメントは Markdown（`docs/` 以下）が真実で、docsify がその場でレンダリングします。

```sh
node docs/serve.js     # → http://localhost:8081
```

公開する場合もビルド工程はありません——`docs/` ディレクトリをそのまま任意の静的サーバに
置けば動きます（docsify・テーマとも vendor 済みで外部 CDN に依存しない。ルーティングは
hash ベースなのでサーバ側の rewrite 設定も不要）。
