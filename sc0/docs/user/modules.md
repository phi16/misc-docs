# モジュール

モジュールは `.sc0` ファイルひとつです。標準ライブラリは `core/modules/` にあり、
CLI はそこをディスク読みします。LSP では開いているファイルの親ディレクトリが探索パスになり、
同じディレクトリの `.sc0` を `import` できます。Web は wasm に焼き込まれた同じソースを使います。

**プログラムとモジュールは同じもの**です。プログラムは宣言の列で、モジュールとして
ビルドされます（Web ではモジュール名 `self`）。特別な `main` はありません。

## import の形

```
import M;                 -- M の公開名を使う（このモジュールを import した側には出ない）
open import M;            -- 使う＋再公開（このモジュールを import した側にも M の名前が見える）
import M (f, T);          -- 選択 import（名前を絞る）
open import M (f, T);     -- 選択再公開
```

- import した名前は非修飾で使えます。`M.name` の修飾参照もできます。
- import の循環は検出され、経路つきで明確なエラーになります。
- `std` は **Prelude として常時取り込み**です（`import std;` は書かない）。
  `std` が `open import base` しているため、基底型・`Vec`・数学関数などは常に非修飾で使えます。
- `prim`（葉の単相演算 `addN` / `addR` …）は `std` が**使うが再公開しない**ため
  Prelude には出ません。raw に触りたいときだけ明示 `import prim;`。

**⚙ 実装メモ（選択 import の細部）**：

- fixity 宣言は選択リストで絞られます（演算子を import しなければ中置も使えない）。
- **インスタンスは選択に関わらず全部見えます**（インスタンス探索はモジュール単位。
  選択リストで辞書を隠すことはできない）。
- 選択リストにない名前の参照は import 時に存在検査されます。

## private

```
private let helper = …;
private opaque gridTopo : (m n : N) -> Topo;
```

`private` を前置した宣言は**そのモジュール内でだけ可視**です（`opaque` / `let` に付けられる）。
`mesh` の `gridTopo` のような内部プリミティブを隠すのに使われています。

## 宣言の順序と再帰

- 宣言は**上から順**に検査・定義されます。前方参照はできません。
- **自己再帰・相互再帰はありません**（`let f = … f …` は書けない）。
  反復は `iterate` / `for`（有界反復）で表します（[評価モデル](user/evaluation.md)）。
- トップレベル宣言は局所的に型が閉じます：ある宣言の型は、その宣言だけを見て決まり、
  後続の使われ方から推論が逆流することはありません。

## 標準モジュールの構成

| モジュール | 役割 |
|---|---|
| `base` | 公開プリミティブ（基底型・`Vec`/`Buffer`・数学関数・`Id`/`J`・`Fin`・`Maybe`）。import なしで自己完結 |
| `prim` | 内部の葉演算（`addN` / `mulR` / `eqB` …）。Prelude に出ない |
| `std` | **Prelude**。`base` を再公開し、オーバーロード層（クラス・インスタンス・演算子・fixity）と `render` / `Array` / `≡` の糖衣を載せる |
| `algebra` | 法則つき数学構造（`Semigroup` … `Ring`） |
| `math` | `N` / `Z` / `Complex` / `Quaternion` の構造インスタンス |
| `mesh` | ハーフエッジトポロジ `Topo` と要素・生成系 |

詳細は [標準ライブラリ](user/stdlib.md)。

**⚙ 実装メモ**：「リテラルの解決は `From`（std）に依存する」ため、`base` には**数値リテラルを
書けません**。`Array = Buffer 1 [k] A` が `base` でなく `std` にあるのはリテラル `1` を含むから、
という配置原則がライブラリ全体を貫いています（リテラルに既定型を与えない No ad-hoc の帰結）。
